# 20261119T1656Z - CDCL SAT solver with independently checked answers

## Task
Level 20 capstone: `ae.sat` CDCL solver (two watched literals, first-UIP learning, backjumping, VSIDS, phase saving, Luby restarts), DIMACS parser, model checker, RUP proof checker, CNF encodings. Overlap check against `benchmark/java/` (j01..j35): no SAT/proof task; no overlap.

## What worked
- Making every answer self-certifying: SAT models go through `ModelChecker`, UNSAT proofs (learned clauses ending in the empty clause) through a `RupChecker` that shares no code with the solver. Tests call one `solveChecked` helper so no result is accepted on belief.
- Differential test against brute force (400 seeded random 3-SAT instances, even seeds near ratio 4.3, odd seeds ratio 5.5) plus known-answer families (pigeonhole, n-queens, Petersen/K4 colouring).
- A mutation (truncate learned clauses in `analyze`) made 6 tests fail, proving the checkers can fail.
- Passed on the second `mvn -q -B clean test` run: 26 tests.

## What failed
1. `DimacsTest`: expected `line 2: unterminated clause` but got line 3, because the text ends in `\n` and the trailing empty "line" updated `lastLine`.
2. `differentialAgainstBruteForceOnRandom3Sat`: my guard "at least 100 UNSAT" failed (92) because ratio 4.3 at 6..14 variables is mostly SAT.

## Root cause
Both were wrong test expectations/fixtures, not solver defects: (1) `String.split("\n", -1)` yields a trailing empty element, and I updated the "last line" marker before skipping blank lines; (2) I chose the clause/variable ratio from the large-n phase-transition value without checking the SAT/UNSAT mix on tiny n, where the threshold is shifted.

## Rule learned
- For end-of-input error positions, define the position as the last line with content and track it after skipping blank lines; test with and without a trailing newline.
- When a randomized differential test asserts a minimum count of each outcome, measure the mix first and mix two generator parameters (e.g. ratio 4.3 and 5.5) so both outcomes are guaranteed by construction.
- For solver/prover code, route every test through a verifying helper (model check or proof check by independent code) and kill-check it by mutating the learning step.
