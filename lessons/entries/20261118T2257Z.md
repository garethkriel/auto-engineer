## Task
Level 20 capstone: `ae.deps`, a semver dependency resolver (Version, npm-style Constraint, Registry port with memory/text adapters, backtracking Resolver with lock preference, install order, atomic Lockfile). Overlap check against `benchmark/java/`: j15-topo only sorts a graph, j19-allocate/j16-ranges/j35-minisql do not parse version ranges or search over candidate versions; the install-order DFS is a minor step here.

## What worked
Design first in TASK.md (prerelease rule, unknown-package and cycle assumptions). Tests used literal tables for every operator form, the semver-spec ordering chain as an all-pairs check, and a seeded brute-force oracle (enumerate every assignment over 5 packages, resolver must succeed iff one exists, result validated by an independent checker and by reachable-closure equality, with a guard that both outcomes occur). Four mutations (prerelease allowance, preferred-first, forward check, prerelease length tie-break) were each killed.

## What failed
First `mvn -q -B clean test`: 13 failures from two defects. (1) `compareTo` had the boolean arguments reversed so a release sorted below its own prerelease, which broke every `<`/`^` upper bound. (2) The forward check threw "unknown package" immediately; seed 128 of the oracle showed a solution exists when another version of the requirer is chosen, which does not depend on the missing package. Fixed in attempt 2: both pass, 40 tests green.

## Root cause
(1) Writing `Boolean.compare(a,b)` for "release is greater" from memory without checking the sign; the all-pairs chain test caught it at once. (2) Mixing a final error condition into the middle of a search: errors that depend on a choice must be recorded as branch failures and only reported when the whole search fails.

## Rule learned
In backtracking searches never throw for a condition caused by a tentative choice; record it as a failure message (deepest wins) and throw only when the search is exhausted. For comparators, test all pairs of a published ordering chain rather than adjacent pairs, and verify completeness with a brute-force oracle on tiny seeded instances.
