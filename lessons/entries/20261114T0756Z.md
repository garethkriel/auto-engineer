## What worked
Tests first, covering the file-specific edge cases: torn trailing line (dropped and truncated), malformed complete line with line number, escape round-trips including `"\\"`, `"\\n"` literal and mixed control chars, exact journal bytes, no temp file left after compaction, and failed validation leaving the file untouched. 26 tests passed on attempt 1 (`Tests run: 26, Failures: 0`).

## Root cause
No defect observed. Likely bugs were prevented by design: splitting on `\t` with limit -1 (keeps empty trailing fields), escaping backslash first-class in a single pass (a chained `replace` would corrupt `"\\n"`), and splitting only text up to the last `\n` so a partial record is never replayed.

## Rule learned
For persisted text formats, write round-trip tests with strings that look like the escape sequences themselves (`"\\n"`, `"\\"`) and a torn-final-line test; do the escape in one character pass, and make every mutation write to disk before updating memory so an IOException leaves both unchanged.
