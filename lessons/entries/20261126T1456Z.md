# Lesson 20261126T1456Z: hash and MAC toolkit (SHA-3/SHAKE, BLAKE2, HMAC, HKDF, PBKDF2)

## Task
Level 20 capstone `ae.hash`: Keccak sponge (SHA-3, SHAKE with streaming squeeze), BLAKE2b/2s (keyed, variable output), and HMAC/HKDF/PBKDF2 generic over a `Digest` interface. Overlap check: `benchmark/java/` names j01-roman..j35-minisql listed; none is a hash/MAC primitive, and no existing skill mentions keccak/blake.

## What worked
- Generating literals with Python `hashlib` (an installed oracle) while authoring, including a "chain of lengths 0..300" digest-of-digests per variant: one literal exercises every block/rate boundary (n-1, n, n+1) of every algorithm. All 41 tests passed on the first run.
- Deriving Keccak round constants (LFSR) and rho offsets (triangular-number walk) in a static initialiser instead of typing tables; wrong values would corrupt every vector, so the vectors double as the table check.
- Making HMAC/HKDF/PBKDF2 take `Supplier<Digest>` let the same code run over JDK SHA-256 (RFC 4231/5869/7914 vectors), SHA3 (JDK `HmacSHA3-256` differential) and BLAKE2b.
- 48-mutant pass: 45 killed on the first sweep; 3 gaps/equivalents analysed below.

## What failed
No test failed, but the mutation pass found two real test gaps: (1) the constructor-copies-the-key test mutated the key after `digest()`, whose trailing `reset()` had already copied the key into the buffer, so an aliased array survived; (2) PBKDF2 block counter written as `0,0,0,i` survived because no test needed more than 255 blocks.

## Root cause
Tests were written from the happy path of the API without asking which code path re-reads each piece of state (here `reset()` re-reads the key) and at which size a multi-byte field first matters (counter byte 2 appears at block 256 = 8192 bytes of SHA-256 output).

## Rule learned
- To test defensive copies, mutate the caller's array and then trigger every path that re-reads the stored copy (`reset()`, second `digest()`), not just the next call.
- For every multi-byte counter/length field add one fixture that crosses each byte boundary (PBKDF2 with 8300 bytes); small fixtures leave the high bytes untested.
- Survivors that are equivalent should be named with their masking reason: counter high word needs >4 GiB input, `outer.reset()` is redundant because `digest()` resets, and an empty HMAC salt equals the zero block because HMAC zero-pads keys.
