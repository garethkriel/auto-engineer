## Task
Level 3 practice: `WordTools` (word frequency, anagram groups, word wrap, common words) using Map, Set, Comparator and StringBuilder.

## What worked
Tests first, with tie cases (equal counts, duplicate and mixed-case anagrams, width exactly equal to line length). Sorted collections (`TreeMap`, `TreeSet`) gave deterministic output with no extra sorting. 10 tests passed, 0 failures.

## What failed
My first retry loop (`mvn ... | tail && break`) exited after one try because the pipe's status came from `tail`, so it looked like success while Maven had failed with "Could not find artifact" (transient). A first draft test also contained a convoluted ternary assertion that could not fail meaningfully; I replaced it with an exact-list assertion before the final run.

## Root cause
Pipe exit status is that of the last command; and I tried to test too indirectly. No code defect.

## Rule learned
Retry Maven by redirecting output to a file and testing `mvn` exit status directly (`mvn ... > out 2>&1 && break`), never through a pipe; assert exact expected values rather than conditional expressions.
