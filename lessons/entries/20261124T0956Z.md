# 20261124T0956Z

## Task
Level 20 capstone `ae.diff`: Myers minimal diff, unified diff format/parse/strict apply/reverse, diff3-style three-way merge. No overlap with benchmark titles; `dir-snapshot-diff` and `rsync-delta` are different algorithms.

## What worked
- Independent oracles: an O(nm) LCS DP for minimality (`changes == n + m - 2*LCS`), GNU `patch` applying our output and our parser applying real `diff -U` output, and `git merge-file` for clean-merge text. All agreed first time.
- Storing only the live diagonal window `[-d-1, d+1]` per Myers round kept memory O(D^2); 40k lines with 20 edits runs in milliseconds.
- Hand mutation (14 mutants) found two real gaps (parse overshoot guard, hand-built hunk with lying counts); both closed with one test each and re-killed.

## What failed
- First `mvn test`: 1 failure of 33. `git merge-file` reported 1 conflict where we reported 3 for edits two lines apart.
- Early in the round a `sed` replacing `<artifactId>` rewrote every artifactId in the pom (dependency and plugins too); caught by diffing against the template before building.

## Root cause
- Test expectation copied an assumption about the reference tool: git's default "zealous" merge joins conflicts separated by a few lines, so conflict counts are not comparable, only presence is.
- Pom edit used a pattern that matched all elements instead of the `CHANGE_ME` placeholder.

## Rule learned
- When differential-testing against an external tool, compare only what the tool's contract fixes (conflict presence, clean text), and note in a comment which output details differ by design (grouping, adjacency).
- Edit `templates/java/pom.xml` copies with `s#CHANGE_ME#<id>#`, then `diff` against the template: exactly one line may differ.
- Parsers that count lines against a header need both a truncation test and an overshoot test (a line of the wrong kind that fits the other counter); only the second kills the `old > oldLen` guard.
- Guard tests for external tools with `assumeTrue(tool --version)` and assert the number of compared cases, so a missing tool is a skip and not a silent pass.
