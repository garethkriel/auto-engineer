# Lesson 20261119T0856Z

## Task
Level 20 capstone: `ae.bitemporal`, an in-memory bitemporal store (valid-time half-open intervals, transaction-time history, as-of reads, atomic multi-key transactions, no-op transactions not recorded, injected non-decreasing clock, `diff`, per-instant `revisions`). Overlap check against `benchmark/java/`: j09-bank, j17-cache, j29-kvlog and j35-minisql have no valid-time intervals or two-axis as-of queries. Chosen after reading rejection reasons for PRs #92/#96 (overlap and stray INDEX edits).

## What worked
Making the canonical form a design decision: every per-key state is an immutable, sorted, coalesced `Timeline`, so "did this transaction change anything" is plain `equals` and the no-op rule needs no special code. Oracle design for the random test: an array of cells per transaction with one extra cell standing for `[N, FOREVER)`, which lets open-ended intervals be compared exactly. The test also asserts that the generator hit both branches (over 1000 recorded transactions and over 20 no-ops). Five mutants (no coalescing, always record, clock check off, `txAtTime` with `<`, no revision de-dup) were each killed.

## What failed
Nothing failed at runtime: 40 of 40 passed on attempt 1. Drafting defects caught before running: leftover unused variables in the randomized test (a `Runnable` plan list, a holder array and a no-op `BiConsumer`), removed during the re-read.

## Root cause
The unused scaffolding came from sketching the test generator before deciding how the oracle records changes; I left half-formed variables behind instead of deleting them once the design settled.

## Rule learned
For versioned or temporal stores: keep one canonical immutable value per key per version so no-ops and equality fall out of `equals`; model open-ended ranges in the oracle with an explicit sentinel cell; test as-of reads at every historical transaction, not just the latest; make the random generator prove it exercised both the recorded and the no-op branch. Re-read generated test drafts for unused variables before the first run.
