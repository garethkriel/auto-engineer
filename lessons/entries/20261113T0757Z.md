# Lesson 20261113T0757Z

## Task
Level 1 arrays: `ArrayOps` with rotateRight, secondLargestDistinct, longestRun.

## What worked
Writing edge-case tests first (negative k, k = Integer.MIN_VALUE, Integer.MIN_VALUE as an array value, all-equal array) so a naive implementation would fail them; all 9 tests passed first run.

## What failed
Nothing failed. Rejected designs: `-k % n` for left rotation (negative remainder in Java) and using `Integer.MIN_VALUE` as a "none yet" sentinel for the second-largest (wrong when the real value is MIN_VALUE).

## Root cause
Java `%` keeps the sign of the dividend, and in-band sentinels collide with legitimate int values.

## Rule learned
Use `Math.floorMod` for wrap-around indexing, and track "present" with a boolean/Optional rather than a sentinel value; test with `Integer.MIN_VALUE` inputs.
