# Lesson 20261113T0857Z

## Task
Level 1 String basics: `StringOps` with runLengthEncode/Decode, isPalindrome, capitalizeWords.

## What worked
Tests first for tricky inputs (multi-digit counts "12x", "0a", "3a2", count overflow "99999999999a", digits in encode input, whitespace preservation); 14 tests passed once the build resolved.

## What failed
First `mvn -q -B test` failed at dependency resolution: junit-jupiter-params 5.11.4 was marked "not found" in the local repo cache from an earlier transient miss. Also my first draft test had a nonsense assertion and one wrong expected value (`"1a11"` is malformed, not "a1"), caught by re-reading before running.

## Root cause
Maven caches a failed download (`.lastUpdated`) and won't retry until the update interval passes; this is an environment issue, not a code bug. The bad test came from writing cases hastily.

## Rule learned
If Maven reports "was not found ... during a previous attempt", re-run with `mvn -U` before changing code. Re-read hand-written expected values for ambiguity (a trailing count is invalid, not a literal digit) before running, and parse counts into a `long` with an explicit overflow guard.
