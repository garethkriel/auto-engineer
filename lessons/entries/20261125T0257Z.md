## Task
Level 20 capstone: `ae.dns`, a DNS toolkit (strict wire codec with name compression, authoritative zone lookup with delegation/wildcard/empty-non-terminal rules, authoritative server, iterative caching resolver with negative caching and bailiwick checks). Overlap check against the 35 `benchmark/java` directory names (listed in TASK.md): none is DNS; j03-lru/j17-cache are key-value caches and j30-miniserver is a socket request/response server, so no shared core.

## What worked
68 tests, passed on attempt 2. Exact resolver query logs (e.g. the glue-less `www.corp.test` walk is five queries in a fixed order) made every caching and bailiwick rule observable; a transport that crafts hostile replies tested poisoning directly; a differential test against a "deepest zone, chase CNAMEs" oracle ran with fresh and warm shared caches and across TTL expiry. A 20-mutant check showed 16 killed, 2 equivalent and 2 real gaps, both fixed with tests.

## What failed
The first run failed 6 tests, all test defects: I hand-typed a question name as `01610003636f6d00` (an extra `00` byte, so the type field decoded as 867) and the custom-transport test logged the raw int address while the expected strings used dotted quads. The mutation check also found two gaps the first suite missed: a resolver that believed NXDOMAIN without the AA flag, and a server with no CNAME-loop guard (the resolver masked it because it detects loops itself).

## Root cause
Hex fixtures written by hand drift by a byte; I did not derive the bytes label by label (`01 61 | 03 63 6f 6d | 00`) before running. For the gaps: a defence implemented in two layers (server loop guard plus resolver loop detection) is only tested at the outer layer unless each layer has its own test.

## Rule learned
Layered protocol code: build hex fixtures from named label/field chunks (`"0161" + "03636f6d" + "00"`) and assert the length, test every layer's own guards with a unit test even when a higher layer repeats the check, and run a mutation pass (copy the project to the scratchpad, per-mutant timeout, classify survivors as equivalent or gap by naming the redundant check) before declaring a security-style validator done.
