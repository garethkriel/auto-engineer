## Task
Level 20 capstone: `ae.lp`, an exact rational two-phase simplex LP solver with an LP text parser and an independent certificate checker (duality for optimal, Farkas for infeasible, feasible point + recession ray for unbounded). Overlap check: no `benchmark/java/` entry involves linear programming or rational arithmetic (nearest names j19-allocate, j35-minisql share no core algorithm).

## What worked
- Making the solver self-certifying: every `Solution` variant carries a certificate and `CertificateChecker` re-verifies it from the model alone. Every test and 1500 random LPs assert "no violations", so sign-convention bugs cannot hide.
- Recovering duals and Farkas vectors by solving `B^T w = c_B` on the final basis with a separate Gauss routine (`y_i = scale_i * w_i`) instead of reading tableau columns; this handled flipped rows and dropped redundant equalities uniformly.
- A vertex-enumeration oracle (choose n active hyperplanes among constraints and x_j=0) gives soundness for optimal and infeasible outcomes without trusting the solver; the outcome mix (optimal/infeasible/unbounded) was asserted with thresholds.
- Kill checks: forcing `scale=1` (no row flip) failed 3 tests; dropping the MIN dual negation failed 4.

## What failed
- First run (49 tests): two failures, both small. A parser message said "expected term" for `x + $`, where the test wanted the unexpected character reported; and my test expected 2 duals for a model with 3 rows (one redundant). Second run: 49 passed.

## Root cause
- Parser: when an expected-token check fires first it hides a more specific lexical error; the character class must be tested before the "missing term" error.
- Test: I counted the constraints after dropping the redundant row in my head, but duals are defined per original row. A hand-written length was derived from the wrong object.

## Rule learned
- For optimisation solvers return a machine-checkable certificate per outcome and verify it with an independent exact checker in every test; add an oracle on tiny random instances and kill-check each sign convention by mutating it.
- In hand-written parsers, classify an unexpected character before reporting a missing token, and state in the test which object (original rows vs reduced rows) a length refers to.
