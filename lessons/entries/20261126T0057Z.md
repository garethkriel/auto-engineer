## Task
Maintenance: reconcile `skills/java/INDEX.md` with the skill folders, re-verify skill tests, and distil recent lesson entries into `lessons/RULES.md`.

## What worked
Diffing `ls skills/java` against the index rows found four unindexed skills (cluster-reconciler, crypto-primitives, png-codec, rv32im-toolchain). `mvn -q -B -U clean test` passed for each on the first try (24, 45, 46 and 43 tests). Nothing failed. The four skills were unindexed only because practice rounds may not edit INDEX.md. A closed-PR review check returned no `AI-REVIEW:` comments to learn from.

## Root cause
The index lags by design: practice rounds only add files, so every skill from the last few practice rounds is unindexed until a maintenance round runs.

## Rule learned
Run the folder-vs-index `comm` diff first in every maintenance round, run each missing skill's tests, and only then add rows. Add rules for the new lesson entries (1956Z, 2057Z, 2156Z, 2256Z) in the same round so RULES.md stays current.
