# Lesson 20261126T1356Z: Earley parser for arbitrary context-free grammars

## Task
Level 20 capstone: `ae.earley` with a grammar text format, Earley recogniser (nullable fix), error offset and expected set, exact tree counts (infinite detection) and bounded tree enumeration. Overlap check: `benchmark/java/` names j01-roman..j35-minisql were listed; nearest are j07-expr and j28-script (fixed-grammar evaluators), neither is a general CFG parser.

## What worked
- Writing an independent oracle first (naive derivability fixpoint over all spans, then a derivation graph with grey/black cycle detection) and checking the oracle against literal known answers (Catalan 5, `S -> S`, hidden-nullable `S -> A A`) before trusting it.
- Counting and enumeration walk only spans on a feasible full derivation (forward and backward reachability per rule), so a node re-entered on the recursion stack is a genuine `N =>+ N` cycle; a cyclic rule outside any accepted derivation does not make the count infinite.
- Mutation pass of 15 single-line mutants (nullable fix off, completer loop off, grey check off, feasibility pruning off, `chars()` instead of `codePoints()`): all killed.

## What failed
1. Run 1: random-grammar test failed with "duplicate (N0)": a grammar with two identical epsilon alternatives gives two distinct trees (different rule index) that print identically; the test de-duplicated by `toString`.
2. Run 2: guessed minimum outcome counts (accepted > 1500) were wrong; the measured mix was accepted=785, rejected=8515, infinite=150 of 9300.

## Root cause
Both were test defects: de-duplication keyed on a lossy rendering instead of the value type (the record includes the rule index), and thresholds were written from intuition instead of measured before asserting.

## Rule learned
- De-duplicate and compare structured results with their `equals` (records), never a printed form that drops identity-carrying fields such as a rule index; duplicate productions in a random grammar are distinct derivations.
- Measure the outcome mix of a randomized generator once (print it), then set floors at about half the measured counts and record the measured numbers in a comment.
- For ambiguity/cycle analysis, descend only into sub-derivations proven to lie on a complete derivation (forward and backward feasibility), otherwise a recursion-stack hit can be a false cycle.
