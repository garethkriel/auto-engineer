# Lesson 20261126T1157Z: JSON Schema (2020-12 subset) validator

## Task
Level 20 capstone: `ae.schema.Validator` over plain Java values: `$ref`, combinators, exact decimals, `contains` counts, `unevaluatedProperties/Items`, deterministic violation pointers. Overlap check: `benchmark/java/` names j01-roman..j35-minisql read; none is a schema validator (j14-json parses JSON text; this task never parses).

## What worked
- Tests first, with a metamorphic suite (`allOf[s,s]`, `not not s`, `oneOf[s,false]`, `$ref` wrapper, `items`/`properties` wrapper all equal `s`) over 1500 seeded random schema/instance pairs.
- Returning an annotation object per schema evaluation and merging a child's annotations only when the child is valid gave correct `unevaluated*` semantics (failed `anyOf` branches, `oneOf` with two matches, failed `if`).
- A TAB-delimited mutation harness with a restoring `trap`: about 50 mutants; survivors exposed one redundant guard and five untested branches.

## What failed
1. Compile error: `int < BigInteger` after changing a helper's return type.
2. Two test defects/design gaps: an `allOf` expectation forgot that 4.5 also violates `minimum`; `unevaluatedProperties: false` reported keyword `false` instead of `unevaluatedProperties`.
3. First draft of the tests contained placeholder assertions (`null == null ? ... : ...`, `List.of(x).equals(x)`), caught by a re-read before the first run and rewritten.
4. Mutation harness: multi-line `from` strings were split by `read` line by line, producing meaningless mutants; only single-line mutants are reliable.
5. Survivors: the `isIntegral` zero guard (redundant: `stripTrailingZeros` of zero has scale 0), a `fine` flag (redundant: the caller discards annotations of an invalid child); untested: `~01` decoding order, 11-digit array index in a `$ref`, truncated `%4` escape, nested `unevaluated*` annotating for its parent.

## Root cause
Guards written defensively duplicated work done elsewhere (a caller already drops invalid annotations), and edge branches of the pointer decoder had no test; test drafts typed quickly contained tautologies.

## Rule learned
- Return annotations or side results as a value from each evaluation and let the caller decide to merge on success only; do not also guard inside the callee.
- Mutation harnesses take one single-line mutant per TAB-separated row; a `NOMATCH` or a multi-line mutant is a harness bug, not a kill.
- For pointer/escape decoders test the order of decoding (`~01`), integer overflow of indexes and truncated escapes explicitly.
- Re-read the first test draft for tautologies before running.
