# 20261118T1456Z: refactor library lending god class (level 18)

## Task
Refactor a messy library lending class (loans, renewals, fines, hold queue, tiers) into Tier enum / Member / Loan record / HoldQueue / Catalog / sealed Result behind the same-signature `Library` facade. Overlap check: no `benchmark/java/` task is a lending/holds system.

## What worked
Abstract contract class holding the literal characterisation table, subclassed twice (legacy, refactored), so both runs share identical expectations. A seeded differential test over 16000 operations with null/padded/unknown names, negative days and fines, plus an assertion that all 20 outcome codes were produced. Copying guard order verbatim gave a green first run (1 attempt).

## What failed
Nothing failed in the final run. In drafting, my differential test had a half-written `giveBack` branch (placeholder `y = null; continue`) that would have silently skipped comparisons; I caught it on re-read before running.

## Root cause
Writing the switch arms quickly with different shapes tempted a skip-path. A differential test that can silently `continue` past a comparison is a test that cannot fail for those ops. A coverage assertion on the set of codes seen would also have exposed such skipping.

## Rule learned
In differential tests never skip a comparison; assert the set of distinct outcome codes seen covers every expected code, and kill-check with two deliberate mutations (one constant in the enum, one limit elsewhere) before trusting green.
