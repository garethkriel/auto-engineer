## What worked
- Writing the placement rule (level = highest differing 6-bit group of `deadline ^ now`, slot = that group of the deadline) in TASK.md before coding made the code and the package-private `checkInvariants()` the same formula; running the checker after every step of 150 seeded random programs against a `PriorityQueue` oracle gave strong coverage (including callbacks that schedule and cancel).
- A boundary table (starts 0,1,63,64,100,4095,... x delays 63/64/65/4095/4096/...) fired exactly at the deadline on the first run.
- Hand mutation check, 25 mutants: 21 killed (2 by timeout, a hang counts as detected), 4 survivors all equivalent, each justified by a structural invariant (the current slot of levels 1-3 is always empty, so a mask including it or a cascade of it does nothing; levels cascade independently so order is irrelevant; `now == deadline` inside every callback so "rearm from now" is the same).

## What failed
- Attempt 1: 41/42 passed. `periodicIsFixedRateAndCatchesUp` expected 96 fires for `advanceTo(1000)` after the timer had reached deadline 40, but the deadline 1000 is `<= target`, so it fires at 40..1000 inclusive = 97. Test defect, no code defect.

## Root cause
I counted the fires as "40,50,...,990" by eye and forgot that `advanceTo(target)` includes a deadline equal to the target; I did not write the arithmetic down.

## Rule learned
- For inclusive-bound counts write the formula as a literal comment (`(last - first) / step + 1`) and state whether the bound is inclusive before writing the number; derive the last expected log entry from it.
- Redundant-looking structure in an algorithm (an always-empty slot, `now == deadline` in callbacks) produces equivalent mutants: justify each survivor by naming the invariant, and add a literal test only if the invariant itself is not covered by the invariant checker.
- Event-skipping simulators (timer wheels): compare against a one-heap oracle with the same tie-break key `(deadline, seq)` and re-arm rules, and make the checker recompute each element's expected position from the current time after every step.
