# Lesson 20261114T0857Z

## Task
Level 6 file I/O: `Snapshot`/`Diff` — SHA-256 directory snapshot with ignore globs, atomic text persistence, diff of added/removed/modified. Overlap check against `benchmark/java/` (roman, wordfreq, lru, csv, intervals, lcs, expr, graph, bank, counter, streams, fileindex): fileindex maps words to files; this hashes contents and diffs trees, so no shared core algorithm.

## What worked
Writing known-answer tests first (SHA-256 of "abc" and of the empty file) pinned the hashing; `@TempDir` plus a helper that creates parent dirs kept fixtures short; `@CsvSource` tables for glob semantics and malformed lines covered many cases cheaply. 22 tests passed on attempt 1.

## What failed
Nothing failed. Risk spotted early: `glob:*.txt` does not match `dir/a.txt` (`*` does not cross `/`), so the glob table test pins that behaviour explicitly.

## Root cause
n/a (no defect). Potential defects avoided: platform-dependent `\` separators in keys (joined path parts with `/`), partially written snapshot files (temp file + atomic move in the same directory), and symlink cycles (symlinks skipped, not followed).

## Rule learned
For file-persistence code, test the round trip, overwrite of an existing file, and that no temp files remain in the directory; for path-keyed maps, build keys from `Path` name elements joined with `/`, never `toString()`.
