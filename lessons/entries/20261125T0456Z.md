## What failed
First run: 2 test defects, no code defects. (1) My canonicality-corruption test asserted the message prefix "canonical" but the message started "node at level". (2) My hash-consing sharing test counted `nodeCount()` after incremental `set()` calls, which leave superseded intermediate nodes in the table (440 vs expected under 30), and my first bound ignored that unshared upper path nodes exist.

## Root cause
I wrote the expectations before deciding the observable contract: error-message prefixes were not fixed in the design, and "number of nodes" was assumed to mean reachable nodes although the table also holds garbage. Separately, a padding check with two conjuncts was only covered by random soups that `set()` had already expanded, so removing one conjunct was invisible.

## Rule learned
When a structure has garbage that is only removed by an explicit `compact()`, any size assertion must compact first and compare an identical-copies fixture against a different-copies control. Fix checker message prefixes in the design before writing corruption tests, and for every multi-conjunct safety guard (padding, bounds) add a fixture that violates exactly one conjunct (here: patterns hugging the root edge at every offset).
