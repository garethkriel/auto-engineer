# Lesson 20261113T1318Z

## Task
Level 2 (classes and objects, constructors): immutable `Interval` with validated constructor, `parse`, merge/intersection, `mergeAll`.

## What worked
Tests first targeted overflow edges (`Integer.MIN_VALUE..MAX_VALUE` length, adjacency at `MAX_VALUE`); implementing adjacency in `long` arithmetic passed all 13 tests on first compile. Sorting a copy kept the input unmutated.

## What failed
`mvn -q -B test` failed repeatedly with "Could not find artifact ..." for different plugin jars each time (junit-params, slf4j, plexus, surefire-shared-utils). No code changed; this is not a code defect.

## Root cause
Flaky proxy to Maven Central: each run fetches some artifacts, fails on others, and Maven caches the failure as `.lastUpdated`, so plain `mvn test` retries do nothing.

## Rule learned
On "Could not find artifact" loop `mvn -q -B -U test` (the `-U` forces re-resolution past cached failures); it took ~5 tries to fill the cache. Don't count these as debug attempts, and only report passed after a run that prints surefire results.
