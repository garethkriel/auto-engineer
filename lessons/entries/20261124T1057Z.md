# Lesson 20261124T1057Z - Chord DHT simulation (level 20)

## Task
`ae.chord`: Chord ring (finger tables, iterative lookup, stabilize/notify, successor lists, join/crash/leave, replicated versioned storage) in a synchronous simulated network, checked against a TreeSet oracle, the paper's m=6 example, seeded churn and a 20-mutant mutation script. Overlap check: no DHT/overlay task in benchmark j01-j35; `consistent-hash-ring` is static.

## What worked
- Writing the oracle (`RingOracle`) and an `Invariants` checker first, then letting `stabilize(maxRounds)` mean "run rounds until the checker is clean", made every convergence, churn and storage test one-liners with a precise failure message.
- A literal anchor from the paper (finger table of node 8, lookup path 8,42,51) caught interval-direction mistakes immediately; an exhaustive m=4 interval test against a walking oracle covered the a==b and wrap cases.
- All 33 tests passed on the first run, so the mutation script was the real quality check.

## What failed
- First mutation run: 2 of 15 valid mutants survived and 2 patterns never matched (my `|`-separated mutant list broke on `||` inside the code). Survivors were test gaps, not equivalent mutants: (1) a graceful-leave test asserted the splice after a `get`, but `get` lazily prunes dead successor entries, hiding the removed splice; (2) read-newest-version never saw divergent replicas because maintenance keeps them equal.
- A hand-over test written for join (keys moving to the new node) also passed with transfer disabled, because later maintenance rounds repair it: the immediate effect needed its own test without rounds.

## Root cause
Self-healing code (lazy pruning, maintenance rounds, replication repair) masks defects in the eager paths, so assertions made after any repair step cannot prove the eager path works. Mutant lists in a delimiter-separated string are fragile for code containing the delimiter.

## Rule learned
For self-healing systems, test each eager path (graceful leave splice, join key transfer, newest-version read) at the moment it acts, before any lookup or maintenance round, and force the divergent state directly (package-private setter) instead of hoping a scenario produces it. Keep mutants as (file, from, to) tuples in a script language, not a delimited string, and treat "pattern not found" as a failure.
