# 20261126T1956Z practice: limit order book (ae.book)

## Task
Matching engine with price-time priority, iceberg orders, IOC/FOK/post-only, self-trade stop, amend/replace. Overlap check: `benchmark/java/` directory names (j01-roman ... j35-minisql) hold no order-matching task; `skills/java/order-analytics` is reporting only.

## What worked
Writing every rule into TASK.md first (notably the FOK scan, which interacts with hidden quantity and self-trade) made the oracle and the production code agree on the first run: 47 tests, 0 failures. A flat-list oracle that re-sorts per match is a genuinely independent structure from TreeMap + LinkedHashMap levels. The generator-mix test (all four statuses >100 times, every reason seen, >1000 trades) proved the differential runs were not vacuous. A quantity-conservation test (`submitted = 2*takerTraded + cancelled + resting`) was derived on paper, after I first drafted a nonsense placeholder expression and replaced it before running.

## What failed
Attempt 1 was a compile error: record component `postOnly` clashed with the wither method `postOnly()` (accessor must return the component type). First mutation run: 4 survivors: an equivalent FOK mutant and three invariant-checker rules with no dedicated test.

## Root cause
Record accessor names are reserved by component names, so a fluent wither with the same name and arity cannot coexist. The FOK survivor was a redundant expression: `cumulative >= qty` is always false at that point because the scan returns as soon as the total reaches `qty`. The invariant survivors were a test gap: the differential test only ever sees valid states, so it cannot kill "checker rule dropped" mutants.

## Rule learned
Name record components differently from fluent withers (`post` vs `postOnly()`); when a mutant survives because the guarded expression is provably constant, simplify the code instead of keeping a dead expression; and give any invariant checker a reflection-built corrupt state per rule (plus a touching-but-valid control) so checker-rule mutants die.
