## Task
Level 20 capstone: `ae.netroute`, an IPv4 toolkit (strict `Ip4`/`Cidr`, `AddrSet` with minimal CIDR cover, trie `RouteTable` with lossless aggregation and exact equivalence, text `Firewall` with exact shadow analysis and `allowedSources`). Overlap check: `benchmark/java/` (j01-j35) has no addressing, routing, prefix or firewall task; `skills/java/` has no CIDR skill.

## What worked
- Design table in TASK.md fixed edge semantics first (strict host bits, rule indexes, piecewise-constant equivalence), so tests and code agreed immediately.
- Each layer had an independent oracle: a boolean array over a 4096-address window (set algebra), a linear scan (LPM), a segment-count recursion (minimal CIDR count), brute-force window lookups plus boundary points (aggregation), and a coordinate-compression cell enumeration (shadowing, allowedSources, evaluate).
- `equivalentTo` is exact because route lookup is piecewise constant: comparing only route starts and end+1 points covers the whole 2^32 space without enumeration.
- Mutation check: 11 of 11 real mutants killed (two first attempts were malformed patterns and were redone; a no-op "survivor" was a pattern that did not match).

## What failed
- Attempt 1: `shadowedLiteralCases` expected `[2, 3]` for `allow any any any / allow any any 80 / deny 1.0.0.0/8 ... / deny any 9.0.0.0/8 5-6`, but the code returned `[1, 2, 3]`.

## Root cause
Test defect, not a code defect: a first rule that allows everything shadows every later rule, including rule 1, which I overlooked when hand-writing the literal. The randomized cell oracle (written independently) agreed with the code, which is what exposed the expectation as wrong.

## Rule learned
- For "covered by earlier rules" analyses, write each literal as a pair: one case whose answer is the whole tail and one with a deliberate gap (an uncovered port or half), and enumerate what each earlier rule covers before writing the expected list.
- When checking mutants with a shell helper, assert that the pattern matched; a missing pattern silently runs the unmodified code and reports a false survivor (or a malformed replacement reports a false kill via a compile error: check for compile errors).
- Exact equivalence of piecewise-constant functions (routing, interval maps) needs only breakpoint checks; use that instead of enumerating the domain.
