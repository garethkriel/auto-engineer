## Task
Level 16 practice: indexable skip list sorted map (`ae.skip.SkipListMap`) with rank/select/countRange via spans. Overlap check: benchmark dir names (lru, cache, segtree, queue, intervals...) are caches, queues and a segment tree; a probabilistic ordered map with order statistics matches none.

## What worked
Writing `checkInvariants()` (strictly ascending level 0, every span equal to the position difference of its link target, size, no links above height) and calling it after every mutation in a seeded differential test against `TreeMap` (5 seeds x 3000 ops, navigation, rank, select, range). 20 tests passed on the second run and on 3 clean repeats.

## What failed
First run: 1 failure, `navigationOnGappedKeys` expected `floor(25) == 10` over keys {10,20,30}; the correct answer is 20. The implementation was right; the hand-written expectation was wrong.

## Root cause
A test defect from not re-deriving a hand-written expectation against the fixture (the differential test against TreeMap, which cannot make this slip, passed).

## Rule learned
For augmented ordered structures (spans, sizes, ranks) keep the invariant checker as a package-private method and run it after every mutation in a randomised differential test; hand-written navigation expectations on gapped keys should be checked against the fixture before the first run, and a failing hand-written case that the differential test passes is a test defect.
