## What failed
Nothing failed in the code. Process slip: I wrapped `mvn` in a 4x loop by mistake (the transient-failure loop from RULES), producing redundant runs and noisy output; only the final run counts.

## Root cause
Habitually applying the Maven negative-cache retry loop before any failure was observed.

## Rule learned
Run `mvn -q -B test` once first and loop only after seeing "Could not find artifact"; to report test counts run `mvn -B test | grep "Tests run:"` instead of dumping the full quiet output (which includes a long JAVA_TOOL_OPTIONS line).
