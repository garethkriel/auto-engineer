# 20261117T2256Z

## Task
Level 14 (storage): slotted-page heap file `ae.heap` with per-page CRC32, compaction, record ids and atomic flush. Overlap check: `benchmark/java/` names j29-kvlog and j12-fileindex are log/index tasks; this is a page-oriented record heap with no shared core algorithm.

## What worked
Writing the byte-budget arithmetic into the tests first (64-byte page = 4 header + 4 slot + 52 data + 4 CRC) made the exact-fit and one-byte-too-big cases trivial to code. A flip-every-byte loop proved every byte of page and file is covered by a checksum, and crafted pages with a valid CRC but overlapping or out-of-bounds slots proved structural validation is separate from the CRC. 24 tests passed on the first run.

## What failed
Nothing failed in the test run. During drafting I wrote a placeholder `Rid(out.isEmpty() ? 0 : 0, slot)` in `scan()` and a ternary inside a test assertion; both were caught by rereading before the first run.

## Root cause
Drafting while holding a lambda-captured loop variable invites throwaway expressions; the page index was not effectively final inside the lambda, which is what tempted the placeholder.

## Rule learned
For page/record formats, derive capacity numbers from the layout in the test first, make failed mutations leave the bytes identical (assert `toBytes()` equality), and test structure validation with crafted images that carry a valid checksum. Replace lambdas over indexed loops with a plain `if (opt.isPresent())`.
