## Task
Level 20 capstone: `ae.broker`, an MQTT-style broker core (topic filters with `+`/`#`/`$` rule, pruning subscription trie, clean/persistent sessions, retained and will messages, QoS 0/1 with in-flight window, pending queue, ack, timed redelivery). Overlap check: `benchmark/java/` j01-j35 has no wildcard-topic, trie-subscription or QoS redelivery task (j13-ratelimit, j24-queue, j34-vclock share no core algorithm); I also rejected a spreadsheet capstone because j21-sheet is a spreadsheet task.

## What worked
- Pure reference matcher (`Topics.matches`) plus the optimised trie, compared on 300 random filter sets x 40 topics (generator reported >1000 matching pairs).
- Seeded 60-run simulation with `checkInvariants()` after every step and an oracle of "owed" QoS 1 payloads per client; asserts acked set equals owed set, no double ack, same packet id never changes payload, and per-client first-delivery order equals publish order.
- 16-mutant hand run with per-mutant timeout and restore in `finally`: 15 killed, 1 survivor (`if (will != null) s.will = will`) that is equivalent because `dropConnection` already nulls the old will.

## What failed
- Attempt 1: one test errored with `filter must be non-empty`. The random generator built a one-level filter from the word `""`, which is an invalid filter. Fixed in the generator (fallback level), not by loosening validation.
- While drafting, the simulation oracle asserted that a resent packet always follows a drained first copy and that the first delivery is never `dup`; both are false when a drop happens before the client drained its outbox. Removed before the first run by re-reading the oracle against the protocol.

## Root cause
Random generators over a grammar with an empty-string alphabet symbol can produce strings the system under test rightly rejects; the validity invariant of generated inputs was not checked first. The oracle drafting error came from modelling "client saw the first copy" instead of "broker sent the first copy".

## Rule learned
- For protocol/session simulations, write the oracle in terms of what the broker has sent and what the client has acked, never what the client has seen, and allow a first sight of a message to carry `dup`.
- When a generator can emit an empty level/word, add a "generated input is valid" test or fallback before the differential test; equivalent mutants should be proved equivalent in the lesson (here: state already reset on the previous path), not killed with a contrived test.
