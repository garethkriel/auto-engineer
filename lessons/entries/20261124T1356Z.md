## Task
Level 20 capstone `ae.rope`: immutable persistent rope (AVL-balanced tree of leaves of at most 32 chars) with concat/split/insert/delete/replace, a line index from cached newline counts, KMP search across leaf boundaries and a package-private invariant checker. Overlap check: listed `benchmark/java/` (j01-roman .. j35-minisql) first; no rope, text-buffer or line-index task (j18-diff is line diff, j12-fileindex file indexing), and no skill holds a balanced string tree (`undo-redo-editor` is command-based). Rejected PR #136 was an overlap rejection, so the check was done before writing the design.

## What worked
- One primitive pair (`join` with spine descent plus rotations, and recursive `split` built on `join`) gave every operation; `replace` is split, split, join, join.
- Layered oracles: literal tables for lines, `StringBuilder` differential (40 seeds x 250 ops, six op kinds, `check()` after every op, op-count floors asserted), `String.indexOf` differential for search, a depth bound derived from the AVL height formula for 100k appends and prepends.
- Package-private `LEAF_MAX = 32` and package-private node constructors let tests cross leaf boundaries with 100-char strings and build corrupt trees for the checker.
- Hand mutation (17 mutants on the core, then 3 on the checker): 12 killed, 5 equivalent, 1 real gap (checker could not fail).

## What failed
- First `mvn test`: 3 failures, all wrong hand-written expectations: I called a 102-character fixture "100 chars" and used 101 as its out-of-range index, and I put the match index of `"ab"*50+"c"` at 97 instead of 98. No code defect. Fixed the expectations (and derived the bound from `LONG.length()`), attempt 2 passed (38 tests).
- Draft tests also contained placeholder expressions (a `.replace(...)` chain, an `aaaa`/`aaab` string built by `replace`) caught by re-reading before the first run.

## Root cause
Hard-coded lengths and indexes written from memory of a fixture instead of derived from it; the fixture length was never counted. Separately, an invariant checker with a dropped rule (`check balance dropped`) survived because balance was only covered indirectly by depth bounds, never by feeding the checker a corrupt tree.

## Rule learned
- Express fixture-dependent bounds as `FIXTURE.length() + 1`, `LONG.length()` etc., and print the fixture length in a comment computed once (`python3 -c "print(len(...))"`), never "about 100".
- Invariant checkers get a dedicated test class that hand-builds one corrupt structure per rule (via package-private constructors) and asserts the message prefix; surviving "checker rule dropped" mutants are test gaps, not equivalents.
- Equivalent mutants seen here: `>=` vs `>` in a rotation choice when equal heights cannot arise from `join`, `<` vs `<=` at a split boundary that returns an empty half, a skip test that only skips empty loops, and a chunk-midpoint rounding that gives another valid balanced shape. Decide by what reads the changed value.
