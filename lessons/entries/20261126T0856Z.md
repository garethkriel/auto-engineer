# 20261126T0856Z — exact units of measure (ae.units)

## Task
Dimensional-analysis library: exact rational conversions, 7-exponent dimensions, a unit-expression parser (`kg*m/s^2`, `(mm)^2`, SI prefixes) and affine temperatures (degC/degF). Overlap check: `benchmark/java/` names j01-roman … j35-minisql read; none is a units/dimension library (j07-expr evaluates arithmetic, not units).

## What worked
- Writing the tests first with an independent factor table inside the test file (published definitions as decimal literals) plus a random expression generator whose tree evaluator uses plain int arrays: 207 tests passed on the first compile-clean run, and the 27-mutant pass still found two gaps, so green-on-first-run was not evidence by itself.
- Control inputs for every rejection (`m^64` vs `m^65`, `(m` vs `(m)`, `m s` vs `m*s`) and a measured outcome mix for the garbage fuzz (`rejected > 500 && accepted > 20`).
- Resource budgets (decimal exponent cap, pow-bit estimate before allocating, factor-bit cap after each parser operation) turned hostile inputs like `(((ft/m)^64)^64)^64` into `IllegalArgumentException`.

## What failed
- Attempt 1: compile error, `Math.checkIndex` does not exist (it is `Objects.checkIndex`). Fixed in attempt 2.
- Mutation pass: two survivors. (16) dropping the denominator half of the factor-bit cap and (22) dropping `Rational.pow`'s size estimate. Both were masked by the other budget (same expression rejected by numerator bits / by the parser cap).

## Root cause
Two overlapping guards hide each other: the test input tripped both, so removing either looked unobservable. The tests exercised the combined behaviour, not each guard separately.

## Rule learned
When two budget/size guards protect the same input, write one fixture that trips only each guard (denominator-only growth `(g^64)^64 * (g^64)^64`; a direct `Rational.of(3).pow(600000)` call that bypasses the parser cap) and mutation-check each guard separately. Also: units/affine code needs the offset isolated by construction (affine units rejected from every compound operation) rather than handled case by case.
