## Root cause
n/a. The usual heap bugs (stale position index after swap, remove-last-slot, change-key needing both sift directions) were pre-empted by always writing `pos[id]` whenever a heap slot is written and by calling siftUp then siftDown(pos[id]) after any in-place key change or replacement.

## Rule learned
For indexed heaps: keep one `pos` array updated on every slot write, make ties deterministic by id so a sorted model can be the oracle, and use a small key range in randomized tests so tie paths are exercised.
