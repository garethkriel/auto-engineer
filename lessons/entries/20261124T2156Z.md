# Lesson 20261124T2156Z

## Task
Optimal paragraph layout (`ae.layout.Breaker`, `TextJustifier`), level 20 capstone: Knuth-Plass total-fit line breaking with box/glue/penalty items, integer badness, hyphen and forced breaks, plus a justified-text renderer. Overlap check: listed all 35 `benchmark/java` ids; none concerns text layout (nearest are j13-ratelimit/j30-miniserver by name only, j18-diff/j06-lcs as different DPs), and skill `text-table` formats tables, not paragraphs.

## What worked
Tests first: literal hand-derived demerit fixtures (e.g. 7344200, 8300), a `BigInteger` brute-force oracle over every subset of legal breaks (1500 seeded instances, 803 feasible / 697 infeasible, 140 hyphen breaks, 67 mid forced breaks, thresholds set from the measured mix), rendering property tests, and an 8-mutant check. Final `mvn -q -B clean test`: 21 tests, 0 failures, passed on attempt 3.

## What failed
Run 1: (a) the large-paragraph test timed out with peak 87462 active nodes; (b) only 351 of 1500 random instances were feasible, so the "feasible > 400" assertion failed; (c) the render test compared a hyphen-ended line without collapsing its justification spaces. Run 2: my new `uniformFromLine` equivalence test used a first-line width smaller than two words, so the random paragraph was infeasible. The first mutation run left one mutant (leading glue after a break not discarded) alive.

## Root cause
(a) The DP key included the line number, and with a constant width many different line counts reach the same break, so keys multiplied; Knuth merges line numbers beyond the last special line. (b) The generator drew stretch 0 and tight widths too often. (c) and the run-2 failure were test fixtures not derived from the item widths. The surviving mutant was a real test gap: no fixture put glue directly after a break.

## Rule learned
When a DP state includes an index that does not affect the future (line number under constant width), add a normalisation parameter and assert the peak state count in a test. Measure a random generator's feasible/infeasible mix and size fixtures from the widths before fixing thresholds. For leading/trailing discardable items, write one fixture whose discarded item would make the line infeasible if kept.
