## Task
Level-20 capstone: `ae.suffix` suffix-array toolkit (prefix doubling, Kasai LCP, substring search, longest repeated / common substring, k-th distinct substring), BWT with sentinel and a sampled FM-index. Overlap check: `benchmark/java/` has no suffix/BWT task; j06-lcs is the subsequence DP, not substring.

## What worked
Tests first against brute-force oracles (sorted suffixes, indexOf, TreeSet of substrings), with seeded random inputs over alphabets of 1-4 letters, so degenerate cases (all-equal text, empty text) came up on their own. 30 tests passed on the first run. Mutation kill-checks on four rules were run afterwards.

## What failed
The first draft of the initial-rank code in `SuffixArray` had placeholder helper methods (`denseRank`, `duplicatesBefore`) left in; I replaced it with `Arrays.binarySearch` over the distinct sorted values before the first run. Kill-check: the mutant "Kasai resets h to 0" survived, because the large-input test only built the SA and never called `lcp`.

## Root cause
A performance test must call every routine whose complexity matters; I timed `build` but not `lcp`, so an O(n^2) regression in Kasai was invisible. The draft placeholders came from writing a helper while still deciding the algorithm.

## Rule learned
For each routine with a complexity claim, put the call inside the time-bounded test on adversarial (periodic / all-equal) input, and confirm by mutating away the amortising step (e.g. `h--` in Kasai) that the timeout fires. Decide the algorithm for helper steps before typing the helper, so no placeholder bodies are written.
