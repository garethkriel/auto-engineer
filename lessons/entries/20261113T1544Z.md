# 20261113T1544Z

## Task
Implement an immutable half-open `IntRange` (level 2: constructors, equals/hashCode, toString).

## What worked
Writing 15 tests first (edge cases: empty range, adjacency vs overlap, int-overflowing length, null args) meant the implementation passed on its first run: 15 tests, 0 failures.

## What failed
Not the code: `mvn` first failed with "Could not find artifact" for plugins/JUnit jars even though curl to Maven Central returned 200. Retrying with `-U` several times resolved a few more artifacts each time until the cache was complete; a later clean run without `-U` passed.

## Root cause
Intermittent proxy/download failures of single artifacts, and Maven caches those failures (negative cache), so plain re-runs fail until forced with `-U`.

## Rule learned
If Maven reports "Could not find artifact" while curl to the same URL returns 200, treat it as transient: retry `mvn -q -B -U test` in a loop (up to ~6 times) before concluding anything, then confirm with a final run without `-U`. Don't count these as debug attempts on the code.
