## What worked
Tests first covered the traps of static state (reset in `@BeforeEach`, a rejected owner must not consume an id) and atomicity (a transfer that fails on receiver overflow leaves both balances unchanged). Implementation passed all 12 tests on first compile.

## What failed
First `mvn -q -B -U test` failed with "Could not find artifact junit-platform-engine ... in central"; the second try succeeded (12 tests, 0 failures). No code changed between.

## Root cause
Same transient proxy download failure recorded in 20261113T1002Z (cached `.lastUpdated`), not a code defect.

## Rule learned
Mutate shared state only after every check and computation that can throw (e.g. compute `Math.addExact` result into a local first); validate arguments before touching static counters so failures have no side effects. For Maven "Could not find artifact", simply retry `mvn -q -B -U test` (didn't count as a debug attempt).
