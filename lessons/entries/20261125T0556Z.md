Level 20 capstone: `ae.merkle` Merkle hash trie with proofs and verified anti-entropy sync (practice/java/20261125T0556Z). Overlap check against the 35 `benchmark/java` directory names (listed in TASK.md): none is a hash tree, proof system or replica reconciliation.

## What worked
42 tests green. An independent recursive oracle for the root hash (written without MerkleMap code) matched after every step of seeded random runs; per-byte proof tamper loops; request-count bounds for sync; a 30-mutant check initially left 10 survivors, which exposed 7 real test gaps (adjacent duplicate bucket entry, extra sibling row, extra sibling in a row, three checker rules never exercised, wrong-count remote of 17 hashes raising IllegalArgumentException instead of IllegalStateException). Those were closed and the final pass left 2 justified equivalent mutants.

## What failed
Four `mvn` runs before green. (1) Test compile error: I called `bucket()` expecting a map but the Remote method returns a list. (2) Production bug: the insert loop created a `Leaf` one level too early (`level == DEPTH - 2`), giving ClassCastException in every test. (3) Test defect: the oracle used `HashMap.computeIfAbsent` recursively, throwing ConcurrentModificationException. I also first wrote two tautological assertions in `hashAtAndChildHashesAreConsistentWithRoot` and removed them on re-read.

## Root cause
(2) I mixed two level conventions (level of the node vs level of its child) in one loop; the leaf belongs at child level DEPTH, which is never reached inside the descent loop. (3) Recursive memoisation through `computeIfAbsent` is illegal on HashMap. The mutation survivors came from tests that only used one malformed shape per rule (a duplicate appended at the end is also caught by the ordering rule, so the adjacent-duplicate check was untested; a missing sibling row was tested but not an extra one).

## Rule learned
For fixed-depth tries, write a comment table "node level / child level / what lives there" before the descent loop and test the first put on an empty map before anything else. For strict verifiers, test the over-long variant of every length check (extra row, extra element, extra byte) as well as the short one, and build duplicate/ordering fixtures so only the intended rule can reject them. Never memoise recursively with `computeIfAbsent`.
