## Task
Level 3 WordStats: tokenizing text, top-N words ordered by a chained Comparator, and grouping into sorted collections.

## What worked
Writing 11 tests first, including an explicit tie-break test (equal counts ordered alphabetically) and an immutability test, led to a pass on the first run: Tests run: 11, Failures: 0. Counting with HashMap.merge and then sorting a list avoids depending on HashMap order.

## What failed
Nothing failed in the code. Running `mvn -q` prints no test summary on success, so the count had to be confirmed with a non-quiet run.

## Root cause
Quiet mode suppresses surefire output, so a silent exit 0 gives no evidence of how many tests ran (a zero-test build would also be silent).

## Rule learned
After a `mvn -q -B test` pass, also run `mvn -B test | grep "Tests run:"` once and record the count, so a pass is never an empty run. Return `List.copyOf` from ranking APIs so callers cannot mutate results, and break ties explicitly in every Comparator.
