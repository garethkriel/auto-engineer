# 20261119T2056Z — explicit-state model checker (level 20)

## Task
`ae.mc`: BFS safety checker (invariants, deadlocks, shortest counterexamples, state bound) and "eventually" liveness checker (lasso via iterative Tarjan), with Peterson/unsafe-mutex/philosopher/jug models. Topic picked after checking `benchmark/` titles for overlap (rejected PR #92 was a benchmark copy).

## What worked
- Differential oracles written first: distance relaxation for safety, greatest fixpoint of EG for liveness, validated traces step by step against `moves`.
- Known-answer models (jugs: 6 steps; 2/4 jugs: 6 states; philosophers: deadlock after 3 moves).

## What failed
- Attempt 1: `differentialSafetyAgainstBfsDistances` round 14 expected a 1-step trace (deadlocked initial state) but got 2: the deadlock was judged when dequeued, so a depth-1 invariant violation discovered earlier while expanding another initial state won.

## Root cause
Mixing "check on discovery" (invariants) with "check on dequeue" (deadlock) breaks BFS shortest-ness when several states share a depth, especially with multiple initial states.

## Rule learned
In BFS checkers, judge every property of a state at the moment it is discovered (same place for all checks); randomized oracle tests with multiple initial states expose ordering bugs that hand-written cases miss.
