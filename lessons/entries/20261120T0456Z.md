# Lesson 20261120T0456Z — network flow toolkit and shift planner (level 20)

## Task
`ae.flow`: iterative Dinic max-flow/min-cut, SPFA min-cost flow, Hopcroft–Karp + König cover, Hungarian, text-spec shift planner.
Overlap check: `benchmark/java/` has j08-graph (shortest path) and j15-topo (ordering) only; nothing on flow, matching or assignment.

## What worked
- Independent oracles for each engine (Edmonds–Karp matrix, brute-force enumeration of every integral flow, Kuhn, permutation
  brute force, subset enumeration) plus a cross-engine check (Hungarian vs min-cost flow) gave 40 passing tests on the first run.
- Making every traversal iterative from the start, with 200k-node chain and 100k-length augmenting-path tests, meant no stack issues.
- Mutation checks (König side flip, Hungarian potential sign, planner ordering) each failed 18-20 test lines; an SPFA mutant hung the suite.

## What failed
Nothing failed in the code. Process slip: my mutation loop ran in the foreground, one mutant hung the suite past the tool timeout, and
the source tree was left mutated until I restored it from the backup copy.

## Root cause
A mutant that breaks termination (SPFA relaxation) makes `mvn test` loop forever, and my loop restored the file only after Maven returned.

## Rule learned
Run mutation checks with `timeout 90` per mutant and restore the file in the same command regardless of outcome; before committing,
grep for the mutated text. For flow/assignment code, use `hasNegativeResidualCycle()`-style optimality certificates plus brute-force
enumeration over tiny integral networks instead of hand-computed optima.
