# word-tools

- **Description:** Text utilities on collections: word frequency (`HashMap.merge` + two-key `Comparator`), anagram grouping (sorted-letter key in a `TreeMap` of `TreeSet`s), greedy word wrap with `StringBuilder`, and sorted set intersection.
- **Language:** java
- **Tags:** collections, map, set, comparator, stringbuilder, text
